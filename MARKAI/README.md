# M.A.R.K. SYSTEM AI

Interfaccia AI avanzata dotata di chat integrata, supporto documenti (RAG), trascrizione vocale e generazione audio/immagini.

## 🚀 Caratteristiche
- 🤖 Chat Core basata su modello GGUF
- 📄 Lettura ed elaborazione PDF (RAG)
- 🎤 Input vocale e trascrizione audio automatica
- 🔊 Sintesi vocale (TTS)

## 🔧 Installazione

1. Clona o scarica questa repository sul tuo computer.
2. Apri il terminale all'interno della cartella del progetto ed esegui l'installazione dei requisiti:
   ```bash
   pip install -r requirements.txt
   ```

## 💻 Avvio

Avvia lo script principale tramite Python:
```bash
python avvia_programma.py
```
Il programma controllerà e scaricherà in automatico l'ultima versione del modello GGUF direttamente da Hugging Face al primo avvio.
